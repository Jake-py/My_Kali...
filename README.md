# 🛡️ RED Kali

**Автор: RED ICE**

Графическое приложение на основе **Python 3 & PyQt6** для работы с OSINT-инструментами, базами утечек данных и сетевыми сканерами Kali Linux. В верхней панели приложения отображаются название **RED Kali** и автор — **RED ICE**.

---

## 📌 Интегрированные инструменты & Вкладки

### 🔍 OSINT (Разведка)
- **Социальные сети**: `Sherlock`, `Maigret`, `Social Analyzer`, `Twint`, `InstaLooter`, `yt-dlp` / `YouTube-DL`.
- **Аккаунты & Утечки**: `theHarvester`, `Sherlock`, `Maigret`.
- **Другие & Метаданные**: `ExifTool`, `SpiderFoot`, `Recon-ng`, `Maltego CE`, `FOCA`.
- **Общий (Все в одном)**: Последовательный запуск выбранных инструментов по единой цели.

### 🌐 Nmap & Сетевые сканеры
- `Nmap` (Сканирование портов, версий сервисов, OS detection, NSE скрипты)
- `Masscan` (Ультра-быстрое сканирование больших сетей)
- `Zmap` (Интернет-масштабное сканирование портов)
- `Amass` (Разведка субдоменов и DNS картирование)
- `Shodan CLI` (Поиск подключенных устройств)
- `WhatWeb` (Определение веб-технологий и CMS)

### 🔍 LookUp Base (Базы Утечек Данных) — *Новое по base.txt*
- **LeakCheck Public API**:
  - Проверка Email, юзернеймов и SHA256-хешей без API-ключей.
  - Подсветка критических скомпрометированных данных (пароли, PIN, карточки).
  - Строгое разделение нулевого результата (`found: 0` / `clean`) и системных ошибок.
  - Соблюдение Rate-Limit (1 запрос в секунду).
  - Клиентская валидация ввода до отправки в сеть.

## 🎨 Особенности интерфейса (из `about_gui.txt` & `base.txt`)

1. **Верхнее меню и вкладки**:
   - `OSINT` — Инструменты разведки с подкатегориями (`Социальные сети`, `Аккаунты`, `Другие`, `Все`).
   - `Nmap` — Сетевые сканеры.
   - `LookUp Base` — Проверка утечек данных (LeakCheck API).
   - `__` — Зарезервированная вкладка для будущих плагинов и кастомных скриптов.
   - `⚙️ Настройки` — Смена цветовой гаммы и регулировка прозрачности обоев `red_ice.png`.

2. **Выделенная Консоль Результатов для каждой вкладки**:
   - Каждая вкладка обладает собственной полноразмерной консолью вывода логов.
   - Реальный вывод с подсветкой синтаксиса и ключевых слов.
   - Кнопки: *Копировать*, *Сохранить отчет (HTML / TXT)*, *Очистить*, *Поиск*, *Автопрокрутка*.

3. **Интерактивные карточки инструментов**:
   - Чекбоксы выбора, быстрые кнопки `☑️ Выбрать все` и `☐ Снять все`.
   - Иконка запуска `▶` без громоздкого текста.
   - Раскрывающиеся панели **«⚙️ Подробности»** с автоматической подстройкой под кириллические шрифты (без обрезания).

4. **Значок Kali Linux & Индикатор Sudo (Слева вверху)**:
   - Значок Kali Linux (`kali.webp`).
   - Кнопка статуса Sudo:
     - При неактивном sudo: медленное красное пульсирование (`SUDO: ВЫКЛ`).
     - При нажатии: запрос пароля sudo / авторизация root.
     - При активном sudo: плавное зелёное пульсирование (`SUDO: АКТИВЕН`).
     - Автоматически подставляет `sudo` для команд, требующих root (`nmap -sS`, `masscan`, `zmap`).
