Лучшие OSINT‑программы прямо в Kali
theHarvester — классика для сбора email, субдоменов и сертификатов. Уже встроен в Kali.
SpiderFoot — мощный автоматизированный фреймворк, можно поднять локальный web‑UI на ноуте.
Recon-ng — модульная платформа в стиле Metasploit, гибкая для кастомных задач.
Maltego CE — визуализация связей и графов, удобно для анализа больших массивов данных.
Sherlock / Maigret — Python‑скрипты для поиска никнеймов по соцсетям.
ExifTool — анализ метаданных фото и документов (GPS, устройство, время).


Инструменты для масштабных интернет‑поисков
SpiderFoot — автоматизированный фреймворк, умеет собирать данные по IP, доменам, email, утечкам, сертификатам.
theHarvester — быстрый сбор email, субдоменов, DNS‑записей, SSL‑сертификатов.
Recon-ng — модульная платформа для разведки, похожа на Metasploit, можно писать свои модули.
Maltego CE — визуализация связей и графов, удобно для анализа больших массивов данных.
FOCA — анализ документов (PDF, DOCX) и метаданных, поиск скрытой информации.
ExifTool — метаданные фото и файлов (GPS, устройство, время).


Инструменты для соцсетей и никнеймов
Sherlock — поиск никнеймов по сотням соцсетей.
Maigret — расширенный аналог Sherlock, охватывает больше платформ и даёт отчёты.
Social Analyzer — Python‑фреймворк для поиска профилей в соцсетях и анализа активности.
Twint — парсинг Twitter без API‑ключей, можно собирать твиты, хэштеги, профили.
InstaLooter — выгрузка фото и постов из Instagram.
YouTube‑DL — скачивание и анализ видео/метаданных с YouTube и других платформ.


Для nmap:
Сетевые сканеры и анализаторы

    Nmap — основной инструмент для сканирования портов, сервисов, ОС‑детекции.

    Masscan — ультра‑быстрый сканер портов, подходит для больших сетей.

    Zmap — сканер для интернет‑масштабных исследований (один порт по всему IPv4).

    Amass — разведка субдоменов, DNS‑картирование.

    Shodan CLI — поиск устройств в интернете (нужен API‑ключ, но можно интегрировать).

    WhatWeb — определение технологий сайтов (CMS, сервер, плагины).
